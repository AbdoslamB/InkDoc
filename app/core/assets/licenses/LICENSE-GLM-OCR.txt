GLM-OCR model weights
=====================

Model:      zai-org/GLM-OCR (https://huggingface.co/zai-org/GLM-OCR)
GGUF build: ggml-org/GLM-OCR-GGUF (https://huggingface.co/ggml-org/GLM-OCR-GGUF)

The model card states: "The GLM-OCR model is released under the MIT License."
The weights carry no separate license file; the standard MIT License text
follows, with the model's authors as the copyright holders.

InkDoc uses the model only, through llama.cpp. It does not use the official
GLM-OCR pipeline's PP-DocLayoutV3 layout model (Apache License 2.0) or the
glmocr SDK (Apache License 2.0).
