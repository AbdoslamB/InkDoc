    How it works

    From file to Markdown in three steps

    And InkDoc does the third one for you.

    1. 1

      Add a file

      Drag it into the window, click to browse, or paste a link to a web page or YouTube video.

    2. 2

      InkDoc converts it

      Auto picks the right engine for each file. The window stays responsive, even with a long queue.

    3. 3

      Open it from Downloads

      The .md file is already saved there under the same name. Nothing to export.

    Auto picks the right engine

    Every file goes to the engine that reads it best.

    invoice.pdf Your file
    Autolooks at each file
    MarkItDownOffice, digital PDFs, web, audio
    GLM-OCR / DoclingScans and photosoptional
    MarkitYAML and XML
    invoice.md saved to Downloads

    PDF results are checked against the PDF's own text. If something is missing and an OCR engine is installed, Auto tries again with it. OCR engines are optional downloads in Settings; InkDoc never downloads them on its own.

    Features

    Everything you need, nothing to set up

    Saves itself

    The moment a conversion finishes, the .md file is in Downloads. No save dialog, no export button. An existing file is never overwritten.

    Downloads
    MDreport (1).mdnew
    MDreport.md
    MDinvoice.md

    Preview and edit

    Read the rendered result or the raw Markdown, fix anything, then copy it.

    Missing-text check

    For PDFs, InkDoc compares the result with the PDF's own text and tells you when pages or tables went missing.

    OCR for scans, when you need it

    Add GLM-OCR (1.45 GB) or Docling in Settings to read scans and photos. Runs on your computer, faster with a GPU.

    Private by default

    Most conversions never leave your computer. No account, no telemetry. Audio, web pages and YouTube links use the internet: see exactly what is sent.

    Windows says “Windows protected your PC”
    1. Click More info.
    2. Click Run anyway.

    This appears because InkDoc isn't signed with a paid certificate. Every release is built on GitHub Actions and lists SHA-256 checksums you can verify.

    macOS says the app can't be opened
    1. Open the app once and close the warning.
    2. Go to System Settings → Privacy & Security.
    3. Click Open Anyway next to the message about InkDoc.

    On macOS 14 and earlier you can also right-click the app and choose Open.

    Run from source

    For developers. Needs Python 3.10 or newer.

    Windows
    git clone https://github.com/AbdoslamB/inkdoc.git
cd inkdoc
python -m pip install -r requirements.txt
run.bat
    macOS / Linux
    git clone https://github.com/AbdoslamB/inkdoc.git
cd inkdoc
python3 -m pip install -r requirements.txt
./run.sh

    Every release lists SHA-256 checksums so you can verify your download.
